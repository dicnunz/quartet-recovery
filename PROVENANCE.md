# Sources and decisions

- Scan: [IMSLP04039, Schubert String Quartet No.12](https://ks15.imslp.org/files/imglnks/usimg/7/7c/IMSLP04039-SchubertStringQuartetNo12.pdf), eight pages, edition metadata 1890 (1965 reprint). Schubert died in 1828. Historical composition and engraving are public domain; no modern score transcription was supplied to OMR. Embedded page images extracted with Poppler `pdfimages` preserve the native raster.
- Annotation: [OpenScore String Quartets via MALerLab/ossq-omr](https://github.com/MALerLab/ossq-omr/tree/7a17e45cddc0b7064fc3a179b62caeb57595e993), score ID7648382, raw `sq7648382.musicxml`. OpenScore annotations are CC0. Reference downloaded only after freeze commit `a29c52a2e920ee4f4b79c2bee6eeb1f7c1bb7c46`; source commit and reference hash are recorded. Dataset metadata helped choose the scan, not infer its notes.
- [Audiveris 5.11.0](https://github.com/Audiveris/audiveris/releases/tag/5.11.0), AGPL-3.0. Linux release, bundled Java25, English Tesseract model. `scripts/prepare.py` changes only CLI `swap` to false to avoid a reproducible batch serialization failure. Modified compiled CLI stays in ignored `build/patch`; exact original source downloaded and hash checked. Recognition warnings and raw `.omr` retained.
- [Tesseract tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast), English trained model, Apache-2.0. URL uses main; content is SHA-256 pinned and a changed download fails.
- Eclipse ECJ 3.44.0 compiles the isolated CLI patch; Eclipse Public License 2.0.
- [Verovio](https://www.verovio.org/), version pinned in requirements, LGPL-3.0. Engraves the unmodified prediction. Original MusicXML part labels “Voice” are retained. Engraved pages are exported without reference corrections.
- [TinySoundFont](https://github.com/schellingb/TinySoundFont/tree/853a0a171759f1ddba0de1442133a75912bbeffa), MIT, renders General MIDI presets 40/40/41/42 as violin I, violin II, viola and cello. [TimGM6mb 1.3-5](https://packages.debian.org/sid/timgm6mb-soundfont), Tim Brechbill and David Bolton, GPL-2; detailed sample provenance and upstream license copied into `licenses/TimGM6mb.txt`. The bundled Debian archive is fetched on demand, not relicensed as MIT.

All input/download byte hashes are in `data/sources.json`. The freeze manifest hashes the exact pixel-derived MXL, XML, extracted events and extraction implementation. Evaluation never changes them. The historical benchmark compares written segments, so tied notes remain separate there even when playback sustains a valid chain. Source-derived playback alignment and reference-assisted evaluation alignment are separate operations.

No claim is made that this is an accurate edition or a human-quality performance. Measure omissions, rhythm defects, accidental mistakes and invalid ties remain. Synthesized audio and film contain these errors and use no reference audio or reference notes.
